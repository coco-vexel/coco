以上为合成材料与人工编排的流程示意，非实际运行记录；不是所有文件都需要在同一次任务中处理。

  1. 选择文件夹

    把项目材料作为本次任务的工作范围。

  2. 明确要求

    指定文件、目标，以及需要保留的内容。

  3. 跟进处理

    查看任务过程，按提示补充信息。

  4. 核对结果

    检查结论与文件，再继续下一步。

为持续的项目工作准备。

找到相关材料

从文件名、路径和类型定位工作区中的文件。处理多份材料时，可以在要求里明确指出它们，不必只围绕当前打开的一份文档。

可以这样开始

“找一下项目资料里的预算表和进展记录，先列出相关文件。”

在文档旁边继续任务

内置编辑器提供文档内容与选区上下文，帮助解释“当前报告”“这个表格”等要求。结合文档预览核对结果，在同一任务中继续补充说明。

让要求更具体

“先检查当前报告的待确认事项，保留已有事实和章节结构。”

选择适合工作的模型

在设置中管理模型服务，添加或获取模型列表，选择当前模型，并测试连接。模型服务与本地工作区分别配置，方便按任务需要选择。

开始前完成连接

配置服务地址与凭据，选择模型，测试连接后开始对话。费用取决于所选模型服务。

准备好文件夹，就有了工作的起点。

安装后配置模型服务，再选择项目文件夹并新建任务。第一次使用，可以从查找材料、阅读内容或整理问题清单开始。

本地工作区意味着完全离线吗？

不意味着。文件位于本地，但任务相关内容可能发送到你配置的模型服务。实际联网与数据处理方式取决于所选服务。

能处理哪些材料？

工作区支持文件查找，以及 Markdown、TXT、CSV、JSON 等文本材料读取。Office 文档通过对应的文档能力和编辑器处理；支持范围因格式、对象和具体任务而异，不代表任意 Word、Excel、PPT 文件都可无损处理。

可以自动整理、移动整个文件夹吗？

当前不要将文件查找能力理解为通用文件管理。批量移动、复制或改写文件并非本页承诺的能力。涉及文档修改时，应明确目标文件和修改范围，并检查实际输出。

需要什么系统？

当前官网列出的系统范围为 Windows 10 / 11 x64。其他系统的公开分发信息尚未提供。

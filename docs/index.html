COCO SYSTEM

三种能力，在同一个文档任务中协作

不是一张抽象架构图。切换查看 Agent、Skill 与 Workflow 在 Coco 中分别怎样参与真实文档工作。

AGENT

先理解文档，再决定怎么做

Agent 结合当前文档与用户目标判断任务，不需要用户反复解释上下文和处理范围。

理解当前现场读取正文、结构、样式、批注与编辑状态。
拆解任务决定需要哪些能力、执行顺序和确认节点。
保持用户掌控遇到不确定或高风险操作时主动请求确认。

内置办公能力审校、改写、翻译、摘要和智能排版。
业务规则沉淀面向合同、公文、财务等场景定制标准。

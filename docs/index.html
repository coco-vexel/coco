让智能体进入文档现场

Coco 的核心不是把大模型塞进侧边栏，而是让智能体围绕当前文档工作：理解上下文、选择工具、拆分步骤、展示过程，并在关键节点交给用户确认。

读懂文档结构

从正文、段落、批注、修订和选区中提取上下文，让模型面对的是可处理的文档语义。

拆解复杂任务

把“检查全文编号”“清理格式”“生成会议纪要”等请求拆成可执行步骤，过程透明可回看。

确认后再写回

对高风险操作提供预览、确认和回滚线索，避免模型输出直接污染原文档。

Skill 把经验沉淀成能力

Skill 是 Coco 的能力单元。它把提示词、处理规则、文档操作和业务经验封装起来，让团队可以持续沉淀专用文档能力，而不是每次从空白对话开始。

内置办公技能

校对、润色、续写、翻译、文档清理、正式公文草拟等常用能力可以直接启用。

业务专属技能

面向合同、财务、政务、公文、纪要等场景定制规则和输出格式，减少人工反复说明。

首页固定入口

高频 Skill 和 Workflow 可以 Pin 到首页，用户打开插件就能直接启动常用处理流程。

把复杂文档任务交给 Workflow

很多文档工作不是一句提示词就能完成。Coco Workflow 可以把读取、分块、模型处理、人工确认、写回和复核串成稳定流程，让团队反复使用同一套处理标准。

流程可复用把编号校审、文档清理、批注生成、内容改写等任务沉淀为一键执行的流程。
过程可见每个节点的输入、输出、耗时和状态都能查看，模型处理过程不再是黑盒。
结果可确认在写回文档前让用户确认关键改动，适合审校、公文、合同等高风险场景。

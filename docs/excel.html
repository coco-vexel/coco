COCO SYSTEM

三种能力，在同一个表格任务中协作

切换查看 Agent、Skill 与 Workflow 如何理解工作簿、运行专业处理，并把结果稳定交付。

AGENT

先理解工作簿，再决定怎么处理

Agent 结合工作簿结构、数据关系和用户目标判断任务，不需要用户反复解释表格位置与处理范围。

理解当前现场读取工作簿、工作表、区域和公式状态。
拆解任务决定需要哪些能力、执行顺序和确认节点。
保持用户掌控遇到不确定或高风险操作时主动请求确认。

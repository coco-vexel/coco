打开、编辑、导出副本。

应用掌握文件来源与结果交付方式，Editor 提供文档编辑界面。

打开文件
通过浏览器 File API 提供 DOCX、XLSX 或 PPTX 字节，建立对应编辑会话。
承载界面
将编辑器挂载到应用提供的 DOM 容器。Word、电子表格与 PPT 使用各自入口。
导出与释放
检查编辑结果与导出限制；切换文件或离开页面时销毁旧编辑会话。

mount 为应用提供的 DOM 元素，bytes 为 XLSX 字节。示例与本地浏览器演示使用相同的公开入口。

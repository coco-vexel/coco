开始之前，
有三件事值得知道。

关于模型、保存位置和数据处理。

需要自己准备 API Key 吗？

不需要。登录后即可使用 Coco 内置模型，账户内含可用额度；你也可以在设置中添加自己的模型服务，使用对应的 API Key 与额度。

文件和会话保存在哪里？

会话与文档状态保存在当前站点的浏览器环境中。更换浏览器或清理站点数据可能影响恢复。

文档内容会发送给模型吗？

任务相关内容会发送到当前选择的模型服务。使用内置模型时由 Coco 提供的模型服务处理；使用自配置模型时，由对应的第三方服务商处理。

范围说明
Word正文 JSON ↔ OOXML / Flat OPC，包含受支持的段落、文本、表格及格式。
PPT文本内容与 Core text body、deck 与 Core model 适配；高级几何、图表、动画有范围限制。
Excel不是 Excel JSON 转换器。
运行时ESM JavaScript，面向 Node.js 和浏览器打包；初始版本不含 TypeScript 声明或 CommonJS 入口。
宿主写回由独立适配器应用转换结果，并检查 gaps 与写回 diagnostics；转换库不直接修改实时编辑器。

BEFORE YOU START

开始使用前，了解这些信息

文件在本地处理，是否意味着内容不会发送给模型？

纯浏览器编辑器演示在浏览器内解析和导出文件，没有文档上传后端。使用 AI Agent 时，为完成任务，相关文档内容可能发送到配置的模型服务。“本地编辑”并不等于“模型离线运行”；请结合所用产品、模型配置和服务商的数据政策判断适用范围。

模型怎么配置？是否收费？

模型服务的接入方式以所用产品和部署配置为准。模型调用可能产生服务商费用，不能从插件可安装或 SDK 的开源许可推断 AI 服务免费。使用前请确认模型来源、访问凭据与计费方式。

会修改原文件吗？

浏览器编辑器演示通过“导出副本”交付结果；插件可能写回当前文档，桌面端的写入行为取决于任务和实现路径。执行前核对目标文件、操作范围及确认提示，重要文档先保留副本。不同入口不承诺相同的撤销或备份行为。

如何反馈兼容性问题？

通过 GitHub Issues 提供 Coco 版本、宿主及版本、操作系统、复现步骤和脱敏示例。请勿公开上传客户文档、个人信息或模型密钥。安全问题请按安全说明反馈。

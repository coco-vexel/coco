安装 Coco Office 插件

已安装 Coco Desktop，可以直接管理本机插件。需要企业部署、容器接入或手动安装时，再选择下方对应方式。

用 Coco Desktop 安装与卸载

桌面应用会检测本机插件状态，不需要复制命令，也不用手动寻找安装目录。

获取桌面应用
  1. 打开插件管理进入 Coco Desktop 的“设置 → 插件管理”。
  2. 选择 Office 平台查看当前状态，然后点击安装、更新或卸载。
  3. 重新打开 Office完全退出对应应用，再重新打开使变更生效。

WPS

一次更新 WPS 的 publish.xml，同时注册 Writer 与 Spreadsheets 两个 Coco 插件入口。

$script = Join-Path $env:TEMP "coco-wps-install.ps1"
Invoke-WebRequest __BASE_URL__/install/wps-install.ps1 -OutFile $script
powershell -ExecutionPolicy Bypass -File $script -BaseUrl "__BASE_URL__"
set "SCRIPT=%TEMP%\coco-wps-install.cmd"
curl -L -f -o "%SCRIPT%" "__BASE_URL__/install/wps-install.cmd" || certutil -urlcache -split -f "__BASE_URL__/install/wps-install.cmd" "%SCRIPT%"
call "%SCRIPT%" "__BASE_URL__"
curl -fsSL __BASE_URL__/install/wps-install.sh -o wps-install.sh
chmod +x ./wps-install.sh
COCO_RELEASE_BASE_URL="__BASE_URL__" ./wps-install.sh
执行后需要完全退出并重启 WPS Writer 与 WPS Spreadsheets。

ONLYOFFICE Desktop

Desktop Editors 需要本地插件入口。脚本会同时安装 Word 与 Spreadsheet 两套独立 GUID/config，入口壳内的 UI/脚本资源仍从当前发布地址加载。

$script = Join-Path $env:TEMP "coco-onlyoffice-desktop-install.ps1"
Invoke-WebRequest __DESKTOP_BASE_URL__/install/onlyoffice-desktop-install.ps1 -OutFile $script
powershell -ExecutionPolicy Bypass -File $script -BaseUrl "__DESKTOP_BASE_URL__"__DESKTOP_API_ARG_PS__
set "SCRIPT=%TEMP%\coco-onlyoffice-desktop-install.cmd"
curl -L -f -o "%SCRIPT%" "__DESKTOP_BASE_URL__/install/onlyoffice-desktop-install.cmd" || certutil -urlcache -split -f "__DESKTOP_BASE_URL__/install/onlyoffice-desktop-install.cmd" "%SCRIPT%"
call "%SCRIPT%" "__DESKTOP_BASE_URL__"__DESKTOP_API_ARG_CMD__
curl -fsSL __DESKTOP_BASE_URL__/install/onlyoffice-desktop-install.sh -o onlyoffice-desktop-install.sh
chmod +x ./onlyoffice-desktop-install.sh
COCO_RELEASE_BASE_URL="__DESKTOP_BASE_URL__" __DESKTOP_API_ENV__./onlyoffice-desktop-install.sh
安装后完全退出并重启 ONLYOFFICE Desktop Editors。Desktop 版不要把 config.json.url 直接改成远端地址，实测会打开空白面板。

ONLYOFFICE Docker

支持两种合并安装方式：在 DocsAPI.DocEditor 配置中同时注入 Word 与 Spreadsheet 的 pluginsData，或用脚本一次写入容器中的两套 sdkjs-plugins。

editorConfig: {
  plugins: {
    pluginsData: [
      "__BASE_URL__/onlyoffice/config.json",
      "__BASE_URL__/onlyoffice/config.excel.json"
    ],
    autostart: [
      "asc.{8D9B5A2C-1F3E-4C7A-9B0D-2E6F1A4C8B30}",
      "asc.{A9551FA7-1158-4A6E-9DE0-9A36684B7934}"
    ]
  }
}
Word:  __BASE_URL__/onlyoffice/config.json
Excel: __BASE_URL__/onlyoffice/config.excel.json
curl -fsSL __BASE_URL__/install/onlyoffice-docker-install.sh -o onlyoffice-docker-install.sh
COCO_DOCKER_APPLY=1 COCO_RELEASE_BASE_URL="__BASE_URL__" bash onlyoffice-docker-install.sh onlyoffice-documentserver
$script = Join-Path $env:TEMP "coco-onlyoffice-docker-install.ps1"
Invoke-WebRequest __BASE_URL__/install/onlyoffice-docker-install.ps1 -OutFile $script
powershell -ExecutionPolicy Bypass -File $script -Container onlyoffice-documentserver -BaseUrl "__BASE_URL__" -Apply
set "SCRIPT=%TEMP%\coco-onlyoffice-docker-install.cmd"
curl -L -f -o "%SCRIPT%" "__BASE_URL__/install/onlyoffice-docker-install.cmd" || certutil -urlcache -split -f "__BASE_URL__/install/onlyoffice-docker-install.cmd" "%SCRIPT%"
call "%SCRIPT%" onlyoffice-documentserver "__BASE_URL__" apply
远端模式不需要改 Document Server 容器，但要求接入方能修改 DocEditor 初始化配置；本地模式会把插件入口壳复制到容器的 sdkjs-plugins，适合无法修改业务系统配置的场景。

Microsoft Office

一次下载并登记 Word 与 Excel 两份 manifest。Windows 可使用脚本侧载；企业环境建议通过 M365 管理中心分别上传两份 manifest。

$script = Join-Path $env:TEMP "coco-microsoft-install.ps1"
Invoke-WebRequest __DESKTOP_BASE_URL__/install/microsoft-install.ps1 -OutFile $script
powershell -ExecutionPolicy Bypass -File $script -BaseUrl "__DESKTOP_BASE_URL__"
set "SCRIPT=%TEMP%\coco-microsoft-install.cmd"
curl -L -f -o "%SCRIPT%" "__DESKTOP_BASE_URL__/install/microsoft-install.cmd" || certutil -urlcache -split -f "__DESKTOP_BASE_URL__/install/microsoft-install.cmd" "%SCRIPT%"
call "%SCRIPT%" "__DESKTOP_BASE_URL__"
Word:  __DESKTOP_BASE_URL__/microsoft/manifest.xml
Excel: __DESKTOP_BASE_URL__/microsoft/manifest-excel.xml
Admin Center: Integrated apps -> Upload custom apps
Windows 脚本会下载并登记两份 manifest。完成后分别在 Word 与 Excel 的「插入 → 我的加载项 → 共享文件夹」中添加 Coco；如果看不到入口，先刷新加载项列表。

验证方式

WPS：分别重启 Writer 与 Spreadsheets，确认两边都出现对应的 Coco 入口。
ONLYOFFICE：分别打开文档与电子表格，确认 Coco Word 与 Coco Excel 都能打开各自侧边栏。
Microsoft Office：分别重启 Word 与 Excel，在共享文件夹中添加对应 Coco 加载项并验证面板。

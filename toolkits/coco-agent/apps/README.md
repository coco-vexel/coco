# Coco Agent 应用包

此目录归档 Coco 应用市场的原始 `.coco-tool` 和 `.zip` 应用包。工具 ID 和版本读自包内 `SKILL.md` 的 `metadata.coco.id` 和 `metadata.version`，文档类型读自 `app.json` 的 `targets`。归档放入 `<工具 ID>/<版本>/<原文件名>`。

例如，超大字打印 `1.0.4` 的归档路径为 `coco.word.large-print/1.0.4/coco.word.large-print-1.0.4.coco-tool`。

## 开源 SDK

Coco Office SDK 采用 Apache-2.0 许可证，通过 `npm install @coco-vexel/coco-office` 安装。Coco 的其他产品采用闭源分发。独立工具包和平台资源以各自的分发条件为准。 [SDK 源码与文档](https://github.com/coco-vexel/coco-office) · [SDK 许可证](https://raw.githubusercontent.com/coco-vexel/coco-office/main/LICENSE)

官网静态页面位于 [docs/](docs/)，维护说明见[官网结构](docs/site-structure.md)。
